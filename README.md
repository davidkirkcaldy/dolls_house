# Project: Doll's House

Note: *This website is currently under construction and therefore contains inconsistencies and errors*

## Purpose of Project

This project has two goals:

+ As a simple learning exercise to create a web site on GitHub Pages

+ Providing a way to inform people who have expressed an interest in the progress of the doll's house.

## Website Description

This project documents the creation of a doll's house. The current pages being worked on are:

+ *Home -* containing brief text describing the house and all rooms.

+ *Furniture -* describes some of the furniture created for the house.

+ *The Build -* here the different stages of the build process are described.

## Using the Website

The run this site locally, simple load the index.html file in your preferred web browser. Alternatively, it is hosted on GitHub at
[Doll's House on GitHub]: <https://davidkirkcaldy.github.io/dollshouse/>
